## Step 1 — 목업 ✅ 완료 (2026-03-17)

### 구현 파일

| 파일 | 설명 |
|------|------|
| `frontend/src/views/MockupView.vue` | 설정 탭 섹션 추가 (1560~1763줄) |

### 구현 상세

**설정 탭 구성 (`activePage === 'settings'`)**

1. **월 시작일 설정**
   - select dropdown (1~28일)
   - 변경 시 `settingMonthStartDay` 업데이트 → 거래 필터/기간 표시 즉시 반영

2. **카테고리 관리**
   - 수입 / 지출 / 저축 탭 전환 (`settingCatFilter`)
   - 카테고리별 태그 chip + 삭제 버튼 (기본값은 삭제 불가)
   - 추가 폼: 이름 입력 → 추가 버튼
   - soft delete: `isDeleted = true` (거래 목록 조회 시 표시, 신규 선택 불가)

3. **결제수단 관리**
   - 카드(신용카드/체크카드) / 현금 / 포인트 타입별 구분
   - 카드 행 클릭 → 인라인 청구 설정 전개
     - 정산일 (1~28일): 이용 마감일
     - 결제일 (1~28일): 출금일
     - "전월 XX일 ~ 당월 YY일 이용분 → ZZ일 출금" 안내 문구
   - 포인트 행 클릭 → 인라인 예산 설정 전개
     - 총 예산 / 현재 잔액 표시 및 수정
   - 현금 타입: 클릭 없음 (설정 불필요)
   - 추가 폼: 이름 + 타입 선택 → 추가

4. **저축 수단 관리**
   - 저축 계좌 목록 (기업은행, 카카오뱅크, 현금 기본값)
   - 추가 / 삭제 기능

### 주요 변경 사항 (기존 대비)

| 항목 | 내용 |
|------|------|
| 반복/할부 설정 섹션 | 설정 탭에서 제거 (홈 탭 거래 목록에서 직접 관리하는 방식으로 결정) |
| 카드 청구 설정 아코디언 | 별도 섹션 → 결제수단 행 클릭 시 인라인 전개 방식으로 변경 |
| 포인트 예산 아코디언 | 별도 섹션 → 포인트 결제수단 행 클릭 시 인라인 전개 방식으로 변경 |
| 카드 타입 | `Card` 단일 → `CreditCard` / `DebitCard` 분리 |
